# Adventskalender für Julia ❤️ — Edition 2

## Inhalt
- `index.html`: Startseite und Dialoge
- `style.css`: elegantes Winterdesign, Schneefall, Animationen
- `script.js`: 24 Botschaften aus dem überarbeiteten Liebesbrief, Freischaltung und Finale

## Bestehende GitHub-Pages-Seite aktualisieren
1. Öffne dein bestehendes Repository `advent-fuer-julia` auf GitHub.
2. Ersetze die drei Dateien `index.html`, `style.css` und `script.js` durch die Dateien aus diesem Paket. Auf GitHub geht das über die jeweilige Datei → Stiftsymbol (für Text) oder über Upload files mit gleichem Dateinamen und Commit.
3. Übernimm die Änderung mit `Commit changes`.
4. Warte kurz, bis GitHub Pages neu veröffentlicht hat, und lade die Webseite neu (ggf. Strg+F5).

## Testen
- `?preview=1` schaltet alle Türchen in der Vorschau frei.
- `?preview=1&day=12` simuliert den 12. Dezember.
- Am 24. Dezember erscheint im geöffneten Türchen die Schaltfläche für den gesamten Liebesbrief.

## Hinweise
- Es wird keine Hintergrundmusik abgespielt.
- Der Kalender ist für 2026 ausgelegt; geöffnete Türchen werden lokal im Browser gespeichert.
- GitHub Pages ist öffentlich; Nachrichten sind im JavaScript-Quellcode einsehbar. Die Datumssperre ist kein sicherer Zugriffsschutz.
- Schicke Julia den Link ohne Vorschauparameter.
